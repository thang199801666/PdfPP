# Cross-engine validation

## Current matrix

The current deterministic corpus contains five pages with:

- text and metadata;
- vector rectangles;
- one image per page;
- five outline entries;
- five URI links;
- one AcroForm text widget.

The corpus was checked with Pdf++, MuPDF 1.28.0, pypdf and Poppler.

| Capability | Pdf++ | MuPDF | pypdf | Poppler |
|---|---:|---:|---:|---:|
| Page count | 5 | 5 | 5 | 5 |
| Metadata | Pass | Pass | Pass | Pass |
| Text markers | Pass | Pass | Pass | - |
| Image count | 1/page | 1/page | 1/page | - |
| URI links | Not exposed by inspector | 5 | 5 | - |
| AcroForm widgets | Not exposed by inspector | 1 | 1 | - |
| Outline entries | Not exposed by inspector | 5 | 5 | - |
| First-page rendering | Reviewed through Poppler | Reviewed through MuPDF | - | Reviewed |

The PDF generated by Pdf++ was also reopened by MuPDF, pypdf and Poppler. All three reported three pages, the expected metadata, and the expected text markers.

## Performance snapshot

Machine: Windows x64, Release build, five-page feature corpus, three median samples.

| Operation | Median |
|---|---:|
| Pdf++ open/text/images through PdfPP.Inspect | 9.093 ms |
| MuPDF open/text | 1.577 ms |
| pypdf open/text | 2.730 ms |
| MuPDF first-page render | 1.851 ms |
| Poppler page count | 19.103 ms |
| Poppler first-page render | 95.300 ms |

The Pdf++ figure includes process startup because the validation inspector is a command-line executable. Use Pdf++.Benchmarks for library-level workload measurements; its feature-corpus snapshot reported 0.096 ms open/page count, 0.359 ms sequential text extraction, and 0.721 ms image enumeration.

These numbers are a validation snapshot, not a universal ranking. The next benchmark iteration must use large real-world PDFs, repeated warm/cold runs, memory peak measurement, and an in-process Pdf++ benchmark equivalent to the MuPDF/pypdf measurements.

## Reproduction

Use tools/validation/feature_benchmark_matrix.py for the semantic matrix and timing run. Use tools/validation/compare_mupdf.py for a focused MuPDF check. PyMuPDF bundles the MuPDF engine; verify its AGPL/commercial licensing before distributing it with a product.
