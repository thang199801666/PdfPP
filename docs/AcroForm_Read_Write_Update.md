# Pdf++ 0.18.0 — AcroForm Read/Write Foundation

## Added

- Public `CPPPdf::PdfAcroForm` API.
- Enumerate AcroForm field trees with inherited `/FT`, `/Ff`, and `/V` values.
- Fully-qualified field names from parent/child field trees.
- Field types: text, button, choice, signature, unknown.
- Field flags: read-only, required, no-export.
- Choice field `/Opt` extraction.
- Widget references and page-index lookup.
- Incremental updates for text and choice values.
- Checkbox/radio button `/V` and widget `/AS` updates.
- `/NeedAppearances true` on updated forms.
- Cycle detection and encrypted-document rejection.

## Example

```cpp
const auto fields = CPPPdf::PdfAcroForm::GetFields("input.pdf");

const auto result = CPPPdf::PdfAcroForm::SetFieldValues(
    "input.pdf",
    "filled.pdf",
    {
        {"Customer.Name", "Thang Nguyen"},
        {"Approved", "true"}
    });
```

## Current limitations

- Appearance streams are not regenerated by Pdf++; `/NeedAppearances` asks the viewer to regenerate them.
- Signature fields cannot be set through the generic value API.
- Direct field dictionaries are readable but incremental editing requires indirect field references.
- Form flattening and appearance generation remain separate milestones.
